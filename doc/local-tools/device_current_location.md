# device_current_location

本地 Android 工具，不依赖远程 MCP。仅在用户询问自己当前位置，或要求从当前位置出发时调用；每次调用只获取一次新定位，不在后台持续追踪。

输入：空对象 `{}`。

输出：经度、纬度（按 `经度,纬度` 顺序）、米级精度估计、定位时间和来源（`gps` 或 `network`）。如需街道、地点名称或路线，再将坐标传给高德地图工具。超时、系统定位关闭或拒绝定位权限时返回工具错误。

首次使用会由 Android 弹出精确/大致位置授权。仅授予大致位置时可能只得到网络定位，精度会降低。当前实现最多等待 20 秒，成功或超时后即停止监听。
