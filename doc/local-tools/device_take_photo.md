# device_take_photo

拍摄手机前方画面，交给当前主 Agent 看图。输入为空对象 `{}`，无需手动按快门；首次使用申请相机权限。

页面显示小型实时预览，等待预览和对焦后自动拍摄。优先使用系统可访问的后置最广视角，没有超广角时回退主摄；拍完释放相机，并保留最近照片缩略图。仅支持前台页面，不支持锁屏或后台拍摄。

照片保存在当前会话独有的应用私有目录，不写入相册，页面销毁时清理。原图文件引用通过独立 `ImageContext` 保留，每次模型请求重新编码为标准 `user` 消息中的 `image_url` / Base64 data URL，后续追问继续带原图。不会自动转换成文字摘要或淘汰图片；累计图片过大时明确报错，建议开启新会话。

原图是拍摄时刻的历史画面，不代表之后的实时环境。新的场景问题需要重新拍摄。

模型输入参考：[DeepSeek 图像理解](https://api-docs.deepseek.com/zh-cn/guides/vision/)。
