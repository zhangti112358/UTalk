# Debug

- `DebugRepository.kt`：提供按会话、轮次读取完整事件，以及按模型调用读取请求快照的只读接口。
- `RequestSnapshotCodec.kt`：序列化模型实际输入与裁剪记录；图片用私有文件引用表示，不记录 Base64 或 API 鉴权信息。
- `DebugScreen.kt`：同一 Activity 内的全屏调试页面，以轮次、消息类型和原文详情的嵌套卡片展示历史；工具调用与返回按原始顺序分别列出，并可查看模型请求。
- `DebugDetailComponents.kt`：提供大触控区域的展开/收起卡片、按需 JSON 格式化、完整原文复制、分段加载长文本及历史图片预览。
- `DebugToolPairing.kt`：根据模型输出顺序、调用 ID 和工具名称配对结果，避免多次调用复用 ID 时显示错误结果。

Debug 页面覆盖聊天界面，聊天组件、Agent 与语音控制器保持存活。新事件通过数据库变更通知自动刷新；大量历史分批读取，参数和结果按需展开。

不展示数据库附带的记录时间、定位、精度等检索元数据，也不修改它们的存储。模型实际输入/工具返回原文中的时间与位置仍完整保留。卡片标题整行可点击，展开内容的底部也有收起按钮；选择、复制正文不会触发收起。

模型快照从本版开始，在模型调用前记录；图片仅以路径展示，快照不是含 Base64 和 HTTP 鉴权头的网络报文。快照表示调用时输入，不代表该次网络请求已经成功。

模型请求卡片分开展示输入 Token 估算与服务端实际输入/输出/总用量；展开裁剪记录可查看卸载前后分项、阈值、校准系数和决策原因。一次用户轮次可能对应多次请求，用量按请求保存，不把累计消耗误当上下文长度。中断、失败及旧版记录可能没有实际用量。
