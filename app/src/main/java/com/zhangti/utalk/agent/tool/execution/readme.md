# 工具执行

- `ToolResultAttachments.kt`：从受信任的本地工具提取图片附件，避免将远端工具的文件路径当作本机文件读取。

负责把模型生成的参数安全地转换为工具调用，并对权限、异常和返回内容进行统一处理。

## 文件

- `ToolArguments.kt`：解析模型生成的 JSON 参数，将 JSON 对象递归转换成工具接口需要的 Kotlin `Map`。
- `ToolInvoker.kt`：从目录查找并调用工具，统一把未知工具和运行异常转换为模型可理解的错误结果。
- `ToolPolicy.kt`：定义调用前的技术策略检查；创建和取消的语义完全交给模型与系统提示词判断，代码只防止同一轮重复创建订单。
- `ToolTurnContext.kt`：保存当前轮用户指令和一次性下单标记，防止模型在同一轮重复发单。
- `ToolResultFormatter.kt`：把 MCP 的文本和结构化返回内容整理成可写入模型上下文的字符串。
