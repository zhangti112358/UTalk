# Agent 上下文

统一管理系统提示词、用户输入、模型输出、工具结果和当前可用工具，并负责把它们组装成模型请求。

`ModelContextPolicy.kt` 仅生成本次模型可见视图，不修改永久历史，也不生成摘要。完整输入估算超过 64K 时，从最早的非保护轮次卸载工具链，目标 48K；对话文本独立超过 16K 时，卸载最早完整轮次，目标 8K。当前轮和前 3 轮、未结束的打车预估轮、最近原图轮受保护，允许暂时超过软阈值。

卸载状态属于单个 Agent 会话，后续请求不会自动恢复已移出的旧工具链或旧文本；重启 Agent 会重置状态，不恢复之前会话。固定提示词和去重后的实际工具定义纳入总预算，但不计入对话文本阈值。工具调用和返回成组移出，工具调用消息中面向用户的文字保留。

估算使用中文 0.8、ASCII 0.4、其他字符 1.0 的基础系数，加 15% 文本余量、消息格式开销和每图 1,536 Token 的预留，不按 Base64 长度算图片。服务端实际输入高于估算时，会话内校准系数只上调（最大 4 倍）；统计缺失或偏低时不降低安全余量。估算不是精确 tokenizer 计数；模型硬边界检查另预留 8,192 输出 Token 和 32K 安全空间，超过时拒绝发送并保留完整历史。

`ContextAssembler.kt` 同时提供实际模型输入及原始/可见上下文数量、按类型移出数量和截断工具 ID，供独立 Debug 模块记录。

## 文件

- `AgentContext.kt`：定义所有上下文元素的统一类型，包括系统提示、用户消息、助手消息、工具结果、工具可用性，以及 TTS 被打断时估算的已播报前缀和完整回答。
- `AgentContextStore.kt`：定义上下文存储接口，并提供线程安全的内存实现；同一个工具不会被重复插入。
- `ContextAssembler.kt`：读取上下文快照，将消息和当前激活的工具分别转换并组装为 `LlmRequest`。
- `ContextTransformer.kt`：提供上下文变换流水线，是以后接入对话摘要、工具结果压缩和工具裁剪的扩展点。
- `ModelContextPolicy.kt`：实现有状态的分层卸载、最近轮次保护和不回退的卸载边界；阈值集中配置。
- `ContextTokenEstimator.kt`：定义可替换的估算接口、预算分项、保守字符估算、会话内实际用量校准和预算参数。
- `ContextProtection.kt`：定义跨轮任务保护接口，第一版保护成功预估且尚未下单的打车轮次。

`ImageContext` 独立保存原图引用和拍摄时间。后续每次模型调用仍包含图片，不以助手描述代替原图；图片只映射为 user 消息，并放在完整工具结果之后。
