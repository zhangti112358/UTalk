# Agent 上下文

统一管理系统提示词、用户输入、模型输出、工具结果和当前可用工具，并负责把它们组装成模型请求。

## 文件

- `AgentContext.kt`：定义所有上下文元素的统一类型，包括系统提示、用户消息、助手消息、工具结果和工具可用性。
- `AgentContextStore.kt`：定义上下文存储接口，并提供线程安全的内存实现；同一个工具不会被重复插入。
- `ContextAssembler.kt`：读取上下文快照，将消息和当前激活的工具分别转换并组装为 `LlmRequest`。
- `ContextTransformer.kt`：提供上下文变换流水线，是以后接入对话摘要、工具结果压缩和工具裁剪的扩展点。
